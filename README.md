# 👛 Pocki — Your Money. Your Tasks. Your Vibe.

**Pocki** is a cute, modern personal finance and task management application built with Flutter. Designed with a playful Gen-Z aesthetic, Pocki helps users manage their daily tasks, track expenses, monitor monthly budgets, and build better financial habits — all in one place.

With a pastel-inspired UI, interactive elements, and a simple user experience, Pocki makes everyday productivity and money management more organized, enjoyable, and visually engaging.

## ✨ Features

- 📝 **Task Management** — Create, organize, and track daily tasks with the *Next Up* section.
- 💸 **Expense Tracking** — Record and manage daily expenses across categories such as food, petrol, transport, dress, and more.
- 📊 **Monthly Budget Management** — Set a monthly budget, monitor spending, and track your remaining balance.
- ➕ **Additional Budget Amounts** — Add extra funds to your monthly budget and keep your budget total updated.
- 📅 **Monthly Expense Overview** — Review expense summaries and monitor spending patterns.
- 🔐 **Authentication** — Sign up and log in securely using Firebase Authentication.
- ☁️ **Cloud Data Storage** — Use Firebase services to store and manage app data.
- 👤 **Personalized Profile** — Customize your profile with your name, nickname, and personal quote.
- 🎨 **Playful UI Design** — Enjoy a clean, pastel-themed interface with rounded cards, colorful icons, and fun stickers.
- 📱 **Responsive Experience** — Designed to provide a smooth and intuitive mobile app experience.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Programming Language:** Dart
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **Design:** Custom pastel UI with a Gen-Z aesthetic
- **Development Tools:** Android Studio, Visual Studio Code, Git, and GitHub

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- A Firebase project configured for the application

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/alshifalebba/Pocki
   ```

2. Navigate to the project directory:

   ```bash
   cd pocki
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Configure Firebase for your development environment.

5. Run the application:

   ```bash
   flutter run
   ```
